# tab-panel

## Description

Description
Tab-Panel — a horizontal panel of tab switches built from the helper Tab component. Controls which content is shown to the user (the tab content itself is outside Tab-Panel).

Behavior
Clicking a Tab switches Selected to the chosen tab (only one is active within the panel).

States
- Default — a row of Tabs with 8px gap, no own background/border

Element anatomy
- A row of Tab elements arranged horizontally with 8px gap

Sizes and spacing
- Gap between tabs: 8px

When to use / not to use
Use: switching between multiple related content sections on the same page.
Do not use: navigation between different pages/routes (use a menu or Breadcrumbs); only one content section.

Related components
Tab — helper component used inside Tab-Panel.
