# tab-panel

## Description

Описание
Tab-Panel — горизонтальная панель переключателей вкладок, собранная из вспомогательного компонента Tab. Управляет тем, какой контент показан пользователю (сам контент вкладок — вне Tab-Panel).

Поведение
Клик по Tab переключает Selected на выбранную вкладку (активна только одна в рамках панели).

Состояния
- Default — ряд Tab с gap 8px, без собственного фона/рамки

Анатомия элемента
- Ряд элементов Tab, расположенных горизонтально с gap 8px

Размеры и отступы
- Gap между вкладками: 8px

Когда использовать / не использовать
Использовать: переключение между несколькими связанными разделами контента на одной странице.
Не использовать: навигация между разными страницами/маршрутами (использовать меню или Breadcrumbs); только один раздел контента.

Связанные компоненты
Tab — вспомогательный компонент, используется внутри Tab-Panel.
